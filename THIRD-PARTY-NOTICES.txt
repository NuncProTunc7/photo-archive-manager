THIRD-PARTY NOTICES - Photo Archive Manager (pam) for Windows, version 1.0.0
==========================================================================

Carried from the licence inventory of pam's packaging spike (M15 10A and its CPython 3.14
addendum), and completed against the artefacts the release ships (M15 Task 15W).

pam's own code is licensed under the MIT License (see LICENSE). The Windows installer also
contains the third-party software listed below. Each keeps its own licence. Each component's
licence text is installed with it, at the path named under "Full text" (paths are relative to
the installed pam folder).

Where a licence requires the corresponding source code to accompany the binary (GPL, LGPL),
the exact source archives of the versions listed here are published as assets of the same
GitHub release as this installer, unchanged from their upstream GitHub tags and checked by
SHA-256 when the release is built: libheif-1.23.6.tar.gz, libde265-1.1.3.tar.gz,
x265-4.3.tar.gz and pillow_heif-1.8.1.tar.gz. There is no written offer; the source is
published with every release. The licence texts that no shipped package carries are installed
in the licenses folder.
