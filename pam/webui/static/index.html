            Keyboard shortcuts

            These work the same way in the list and in the large preview.

            X
            Approve this name
            Z
            Skip this name — pam leaves the file called what it is called now
            C
            Edit this name yourself
            ↑ ↓
            Previous / next name in the list
            ← →
            Previous / next photo in the large preview, without closing it
            Space
            Select this name, to approve or skip several names together
            Enter
            Open or close the large preview
            ?
            Show or hide this list of shortcuts

            X and Z also take a decision back. Press X on a name you have already approved — or Z on one you skipped — and it goes back to not decided, leaving you on that row instead of moving you on.

            Two more things worth knowing: the large preview (Enter) has a Why? button that shows where each part of the name came from, and a name you have edited keeps a ↺ button that puts pam's own name back. Deciding in the large preview moves you straight to the next photo you have not decided yet.

            Nothing is renamed until you confirm. Typing in the name box turns these keys off.
